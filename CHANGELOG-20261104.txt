=====================================================================
1. WHAT THIS APP IS
=====================================================================
Single-user local ERP, POS-first. Only active modules: POS, Inventory (with Categories + Deleted tabs), Suppliers, Sales/Receipt.
Currency: tugrik "₮". money() filter prints whole amounts as 1,900,000₮ (no ".00"); decimals print as 1,900,000.50₮.

Removed from the earlier Vortex-inspired build at user request:
- stock locations / per-location stock
- stock moves / transactions
- transfers
- cash sessions (opening/closing till, session reports)
- separate Categories page (merged into Inventory)
- separate Deleted-products page (merged into Inventory "Deleted" tab)
- dashboard (POS became the main interface)
- payment methods CashPay and leasing (rows deleted from payment_methods)
Note: some old tables (stock, stock_movements, cash_sessions, locations) may still physically exist in erp.db but nothing in app.py reads or writes them.

E. Animation rebuild (the "choppy" complaint)
What was wrong: animations were repainting the main thread — transitions on background/box-shadow/border-color/filter,
CSS gradients (gradients are NOT interpolatable, so hover looked like a hard cut), a 180px radial-gradient ripple on
every button, and backdrop-filter: blur(10px) on the modal.
What it is now (compositor-only: transform + opacity):
- :root easings: --spring cubic-bezier(.2,.9,.3,1) for interactive states, --spring-out cubic-bezier(.16,1,.3,1) for
  modal/dropdown entrances.
- buttons: transition transform .16s var(--spring); hover translateY(-1px); active translateY(1px) scale(.985) .09s.
- ripple pseudo-elements removed (leftovers `.qtybox .btn.tiny::after{content:none}` and `.sug::after{content:none}` are inert).
- product card hover no longer swaps gradients (border + static box-shadow only).
- modal: fade-in .20s backdrop + modal-rise .28s translateY(12px) only; backdrop-filter removed.
- dropdown: suggest-in .18s translateY(-4px) only.
- `@media (prefers-reduced-motion: reduce)` disables animation/transition.
Reference used earlier: Chrome "Modern Web Guidance" physics-based easing advice (animate transform/opacity, avoid
animating blur/backdrop-filter, spring-ish curves).
